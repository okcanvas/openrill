# Implementation Sequence

## 규칙

- STEP을 건너뛰지 않는다.
- 다음 STEP은 직전 packaged baseline을 새로 추출해 시작한다. STEP001의 입력은 STEP000A OpenRill identity 기준선이다.
- 참조 분석과 제품 구현을 같은 파일에서 섞지 않는다.
- 하나의 STEP에 DB schema, protocol, UI, connector를 무리하게 함께 넣지 않는다.
