# ADR-0011: Browser Ui Before Desktop Shell

- Status: Accepted for planning baseline
- Date: 2026-08-01

## Decision

제품 흐름을 browser UI로 먼저 닫고 desktop shell은 배포 단계에서 선택한다.

## Consequences

- 이후 STEP의 파일·계약·수용 기준은 이 결정을 위반할 수 없다.
- 변경하려면 새 ADR이 이 ADR을 supersede해야 한다.
