# ADR-0003: Windows First Loopback Host

- Status: Accepted for planning baseline
- Date: 2026-08-01

## Decision

첫 live target은 Windows이고 Host는 loopback foreground로 시작한다.

## Consequences

- 이후 STEP의 파일·계약·수용 기준은 이 결정을 위반할 수 없다.
- 변경하려면 새 ADR이 이 ADR을 supersede해야 한다.
